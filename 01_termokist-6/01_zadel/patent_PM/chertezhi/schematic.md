# Электрическая схема ТермоКисть-6

## Компоненты

| Обозначение | Тип / Модель | Назначение |
|---|---|---|
| MCU | nRF52840 | Микроконтроллер BLE 5.0 |
| NTC ×6 | 10 кОм NTC | Термисторы измерения температуры |
| H-мост | DRV8837 | Управление нагревательным элементом |
| Нагреватель | NiCr провод ∅0.3 мм | Резистивный нагрев |
| PCM | Воскосодержащий композит | Аккумулятор тепла (фазовый переход) |
| Дисплей | SSD1306 0.96" OLED | Индикация состояния |
| BLE-модуль | Встроенный nRF52840 | Связь с мобильным приложением |
| Аккумулятор | LiPo 3.7V 18650 3000мАч | Автономное питание |
| Стабилизатор | TPS63020 | DC-DC 3.3V Buck-Boost |

## Соединения

| От | Куда | Интерфейс |
|---|---|---|
| NTC ×6 | MCU | ADC AIN0–AIN5 |
| MCU | H-мост (DRV8837) | GPIO PWM + DIR |
| H-мост | NiCr нагреватель | DC |
| MCU | SSD1306 OLED | I2C SDA/SCL |
| LiPo 3.7V | TPS63020 | Питание |
| TPS63020 | MCU | 3.3V |

## Принцип работы

MCU считывает температуру с 6 термисторов, вычисляет тепловой баланс
по RC-модели (C·dT/dt = Q − (T−T_окр)/R + Q_метаб), управляет PWM
нагревателя через H-мост. BLE-канал передаёт данные в мобильное приложение.
