## 1. Наименование и область применения

Разработка портативного LAMP-анализатора с библиотекой из 7 ДНК-тест-систем для экспресс-диагностики инфекционных заболеваний животных и видовой идентификации мяса/кормов.

Применение: Ветеринария / Животноводство / Ветеринарно-санитарная экспертиза / Контроль качества кормов и пищевых продуктов.

## 2. Цель работы

Создание портативного LAMP-анализатора (≤50 000 ₽, ≤500 г, 4 лунки) с библиотекой из 7 ДНК-тест-систем для экспресс-диагностики при 65 °C с колориметрической детекцией (TRL ≥ 5).

## 3. Проблема

ДНК-диагностика инфекционных заболеваний животных и идентификация видовой принадлежности мяса/кормов требуют ПЦР-ампликатора стоимостью 500 000–3 000 000 ₽ и квалифицированного персонала. Метод LAMP работает при 65 °C без термоциклера, давая результат за 30–60 мин с детекцией по изменению цвета. Аналогов комплекса «7 тест-систем + портативный LAMP-анализатор» не обнаружено.

## 4. Задачи

1. Разработка LAMP-праймеров (4–6 шт. на мишень) для 7 ДНК-тест-систем
2. Проектирование нагревательного блока с PID-регулированием (65 ± 0,5 °C)
3. Разработка PCB с nRF52840, фотодиодами, OLED
4. Корпус из PLA (3D-печать) + алюминиевый блок
5. BLE 5.0 — передача результатов на мобильное приложение
6. Стендовые испытания: калибровка NTC, фотодиодов
7. Валидация на 50+ образцах с референсной ПЦР-верификацией
8. Подача заявки на ПМ и регистрацию ПО
