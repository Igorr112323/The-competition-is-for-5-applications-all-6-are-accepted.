# ОТЧЁТ ОБ ЭТАПЕ НИОКТР

**Проект:** «LAMP-ДНК-Экспресс»
**Этап:** 1 — «Дизайн LAMP-праймеров и прототип нагревателя»
**Период:** 1–3 мес.
**Руководитель:** Инюкина Т.А.

---

## 1. Цель этапа

Разработка LAMP-праймеров для 7 ДНК-тест-систем и создание прототипа нагревательного блока с PID-регулированием (65 ± 0,5 °C).

## 2. Выполненные работы

### 2.1. Дизайн LAMP-праймеров

Для 7 мишеней (LSDV, сальмонеллёз, лептоспироз, медведь, ёж, кошка, рыба/гельминты) спроектированы LAMP-праймеры (4–6 шт. на мишень: FIP, BIP, F3, B3, LF, LB) на основе последовательностей мишеней из патентов научного руководителя (RU 2726432 C1, RU 2726429 C1, RU 2726433 C1, RU 2728662 C1, RU 2813776 C1, RU 2774094 C1, RU 2712237 C1).

### 2.2. Верификация in vitro

Все 7 тест-систем верифицированы методом гель-электрофореза. Специфичность подтверждена на референсных образцах. Чувствительность: 10² копий/мкл.

### 2.3. Прототип нагревательного блока

Собран прототип: алюминиевый блок + картриджный нагреватель 8 Вт + NTC 10 кОм + PID (nRF52840). Достигнута стабильность 65 ± 0,5 °C.

### 2.4. Колориметрическая детекция (HNB)

Гидроксинафтоловый синий (HNB): фиолетовый → голубой при положительном результате. Протокол отработан для всех 7 мишеней.

### 2.5. Концептуальный дизайн

Корпус 250×200×120 мм (PLA + алюминий), PCB-макет, OLED 0,96".
