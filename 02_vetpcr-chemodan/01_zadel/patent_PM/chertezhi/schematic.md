# Электрическая схема ПЦР-анализатора ВетПЦР-Чемодан

## Компоненты

| Обозначение | Тип / Модель | Назначение |
|---|---|---|
| MCU | nRF52840 | Микроконтроллер BLE 5.0 |
| Пельтье | TEC1-12706 | Элемент Пельтье 12В 6А |
| Драйвер Пельте | DRV8837 | H-мост управления |
| Фотодиод FAM | OPT101 | Фотодиод + усилитель 470 нм |
| Фотодиод HEX | OPT101 | 530 нм |
| Фотодиод ROX | OPT101 | 580 нм |
| Фотодиод Cy5 | OPT101 | 630 нм |
| GPS | NEO-6M | GPS-модуль UART |
| Питание | LiPo 18650 3.7V 3000мАч | Аккумулятор |
| Стабилизатор | TPS63020 | DC-DC 3.3В Buck-Boost |
| Термопара | MAX31855 | Термоэлектрический датчик |

| От | Куда | Интерфейс |

| MCU | Пельтье | PWM GPIO |
