# Заявка на государственную регистрацию программы для ЭВМ

## 1. Наименование ПО
ВетПЦР-Аналитик версия 1.0

## 2. Назначение
Управление портативным ПЦР-анализатором, обработка кривых амплификации, определение Ct-значений, передача результатов через BLE

## 3. Платформа
nRF52840 / Android

## 4. Язык(и) программирования
C (прошивка), Kotlin (приложение)

## 5. Функциональные возможности
1. Управление температурным циклированием (55–95 °C)
2. 4-канальная флуориметрическая детекция (FAM/HEX/ROX/Cy5)
3. Автоматическое определение Ct-методом порогового значения
4. GPS-привязка результатов
5. BLE-передача на мобильное приложение
6. Экспорт результатов в CSV/JSON

## 6. Условия использования
Программное обеспечение разработано в рамках НИОКТР, финансируемого грантом
Фонда содействия инновациям (ФСИ «Старт-Пром-1», очередь 4).

## 7. Интеллектуальная собственность
Права на ПО принадлежат исполнителю НИОКТР. Патентование РИД финансируется
из собственных средств заявителя и не включено в бюджет гранта.

## 8. Аннотация
ВетПЦР-Аналитик — программное обеспечение, обеспечивающее управление портативным пцр-анализатором, обработка кривых амплификации, определение ct-значений, передача результатов через ble.
Версия 1.0 является первой публичной версией, прошедшей стендовые испытания.
