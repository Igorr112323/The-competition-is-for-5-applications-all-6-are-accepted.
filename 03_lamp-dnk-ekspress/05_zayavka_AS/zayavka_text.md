## 1. АННОТАЦИЯ

Проект «LAMP-ДНК-Экспресс» — телемедицинский комплекс экспресс-диагностики днк на основе изотермической амплификации (lamp). Научная новизна — из патентная заявка на ПМ патентов Инюкина и публикаций.

---

## 2. ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ

| Параметр | Значение |
|----------|---------|
| Метод | LAMP (Loop-mediated isothermal amplification) |
| Мишени | 7: LSDV, сальмонеллёз, лептоспироз, + 4 контрольных |
| Время анализа | 30-45 мин (изотермическая амплификация при 65°C) |
| Детекция | HNB (гидроксинафтоловый синий) + фотодиоды |
| Нагреватель | PID, 65±0.5°C, картридж 8 Вт |
| Питание | Аккумулятор 3.7V, 3000 мА·ч (автономно 8 ч) |
| Связь | BLE 5.0 → Android-приложение |
| Масса | ≤0.5 кг (в кейсе ≤2 кг) |
| Кейс | Чемодан IP67, 300×200×100 мм |
| Стоимость | ≤100 000 ₽ |

---

## 3. НАУЧНАЯ НОВИЗНА

1. **Портативный LAMP-анализатор в формате «кейс» (чемодан) с 7 мишенями**
2. **Колориметрическая детекция (HNB) + фотодиодная регистрация → объективный результат**
3. **BLE-передача результатов на Android → телемедицинская интеграция**
4. **Автономное питание 8 ч + PID-нагреватель 65±0.5°C**
