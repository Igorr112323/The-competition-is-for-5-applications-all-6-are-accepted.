# Электрическая схема Паразит-Контроль

## Компоненты

| Обозначение | Тип / Модель | Назначение |
|---|---|---|
| SBC | Raspberry Pi 4B | Одноплатный компьютер |
| Камера | Sony IMX477 HQ Camera | 12.3 МП, CSI-2 |
| LED кольцо | WS2812B ×24 | RGB-подсветка 5500K |
| Драйвер LED | PCA9685 | ШИМ-драйвер 16 каналов |
| Питание | 5V 3A DC-DC | Стабилизированный источник |
| Дисплей | ST7789 1.3" | IPS 240×240 SPI |
| Кнопка | Тактовая | Пуск/Стоп |

## Соединения

| От | Куда | Интерфейс |
|---|---|---|
| Камера | SBC | CSI-2 шлейф |
| Драйвер LED | SBC | I2C SDA/SCL |
| LED кольцо | Драйвер LED | PWM OUT |
| Дисплей | SBC | SPI MOSI/SCK/CS |
| Кнопка | SBC | GPIO |
| Питание | SBC | USB-C 5В |

---
*Текстовое описание электрической схемы. Графическая схема выполнена в формате DXF.*
