# Заявка на государственную регистрацию программы для ЭВМ

## 1. Наименование ПО
Паразит-Детект версия 1.0

## 2. Назначение
Обнаружение и подсчёт личинок Eustrongylides spp. на изображениях мышечной ткани рыб с использованием нейронной сети YOLOv8n

## 3. Платформа
Raspberry Pi 4B / Python

## 4. Язык(и) программирования
Python

## 5. Функциональные возможности
1. Захват изображения с камеры Sony IMX477
2. Предобработка (нормализация, аугментация)
3. Детекция личинок YOLOv8n (mAP≥0.85)
4. Подсчёт объектов и классификация по стадиям
5. Генерация протокола экспертизы (PDF)
6. Экспорт данных в ЛИС (HL7/FHIR)

## 6. Условия использования
Программное обеспечение разработано в рамках НИОКТР, финансируемого грантом
Фонда содействия инновациям (ФСИ «Старт-Пром-1», очередь 4).

## 7. Интеллектуальная собственность
Права на ПО принадлежат исполнителю НИОКТР. Патентование РИД финансируется
из собственных средств заявителя и не включено в бюджет гранта.

## 8. Аннотация
Паразит-Детект — программное обеспечение, обеспечивающее обнаружение и подсчёт личинок eustrongylides spp. на изображениях мышечной ткани рыб с использованием нейронной сети yolov8n.
Версия 1.0 является первой публичной версией, прошедшей стендовые испытания.
