## 1. Название программы

НавигАнсамбль — адаптивный программный модуль иерархического ансамблевого прогнозирования траектории для навигации мобильных роботов.

## 2. Область применения

Автономная навигация мобильных роботов (складская логистика, сельское хозяйство, промышленность). ROS2 Humble.

## 3. Функциональное назначение

Модуль принимает данные одометрии (/odom), LiDAR (/scan) и IMU (/imu), прогнозирует позицию и скорость робота на горизонт 10 секунд с точностью ±5 см, публикует /predicted_pose для Nav2.

## 4. Архитектура

4-уровневый ансамбль:
- Уровень 1: ARIMA (линейный тренд)
- Уровень 2: Random Forest (нелинейные зависимости)
- Уровень 3: Gradient Boosting (взаимодействия датчиков)
- Уровень 4: Мета-модель (взвешивание прогнозов)

## 5. Язык и платформа

Python 3.10+, C++ (ядро инференса). ROS2 Humble. x86_64 / ARM64.

## 6. Лицензия

Apache 2.0.
