# РЕФЕРАТ ПРОГРАММЫ ДЛЯ ЭВМ
## «НавигАнсамбль»

---

Программа предназначена для прогнозирования траектории мобильных роботов на горизонт 10 секунд с точностью ±5 см. Реализует иерархический четырёхуровневый ансамблевый метод (ARIMA + Random Forest + Gradient Boosting + мета-модель).

Модуль совместим с ROS2 Humble, принимает данные одометрии, LiDAR и IMU, публикует прогноз позиции. Время инференса: ≤10 мс. Платформа: x86_64 / ARM64. Язык: Python 3.10+ / C++.
