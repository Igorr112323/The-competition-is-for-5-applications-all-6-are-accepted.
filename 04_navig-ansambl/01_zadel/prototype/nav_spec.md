## 1. Наименование и назначение

НавигАнсамбль — ROS2-пакет иерархического четырёхуровневого ансамблевого прогнозирования траектории мобильных роботов (ARIMA + Random Forest + Gradient Boosting + мета-модель).

## 2. Основные ТТХ

| № | Параметр | Значение |
|---|----------|----------|
| 1 | Горизонт прогноза | 10 сек |
| 2 | Точность позиционирования | ±5 см |
| 3 | Время инференса | ≤10 мс |
| 4 | Частота обновления | ≥10 Гц |
| 5 | ROS2-совместимость | Humble |
| 6 | Входные данные | LiDAR + IMU + одометрия |
| 7 | Платформа | x86_64 / ARM64 |
| 8 | Язык | Python 3.10+ / C++ |
| 9 | Лицензия | Apache 2.0 |
| 10 | Формат | ROS2-пакет |

## 3. Структура пакета

- `ensemble_node.py` — ROS2-узел
- `arima_model.py`, `rf_model.py`, `gbm_model.py`, `meta_model.py` — уровни ансамбля
- `preprocessor.py` — предобработка данных
- `config.py`, `utils.py` — конфигурация и утилиты
- `models/` — обученные модели (pkl)
- `launch/` — ROS2 launch-файлы
- `test/` — unit-тесты

## 4. Зависимости

- ROS2 Humble
- Python 3.10+
- NumPy, scikit-learn, statsmodels, CatBoost
