# Электрическая схема ОптикоЗор-2,0

## Компоненты

| Обозначение | Тип / Модель | Назначение |
|---|---|---|
| FPGA | Xilinx Zynq UltraScale+ | Программируемая матрица |
| CMOS линейка | 4K CMOS Line Scan | Строчный сенсор 4096 пикселей |
| АЦП | ADS8860 | 16-бит SAR АЦП |
| LED гиперспектр | OSRAM OSLON | 400–900 нм |
| Драйвер LED | TLC59711 | 12-канальный ШИМ |
| Шаговый двигатель X | NEMA 17 | Позиционирование пластины |
| Драйвер шаг. | TMC2209 | Сверхтихий драйвер |
| Ethernet | KSZ9031 | Gigabit PHY |
| Питание | 24V PSU | Промышленный источник |

## Соединения

| От | Куда | Интерфейс |
|---|---|---|
| CMOS линейка | FPGA | LVDS |
| АЦП | FPGA | SPI |
| Драйвер LED | FPGA | SPI |
| LED гиперспектр | Драйвер LED | PWM OUT |
| Шаговый двигатель X | Драйвер шаг. | STEP/DIR |
| Драйвер шаг. | FPGA | UART |
| Ethernet | FPGA | RGMII |
| Питание | FPGA | 12V → DC-DC 3.3/1.0В |

---
*Текстовое описание электрической схемы. Графическая схема выполнена в формате DXF.*
