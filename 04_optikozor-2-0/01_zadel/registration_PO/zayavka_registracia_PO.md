# Заявка на государственную регистрацию программы для ЭВМ

## 1. Наименование ПО
ОптикоЗор-Inspect версия 1.0

## 2. Назначение
Высокоскоростной контроль поверхности полупроводниковых пластин: обнаружение, классификация и картирование дефектов

## 3. Платформа
FPGA Xilinx Zynq UltraScale+ / Linux

## 4. Язык(и) программирования
VHDL (FPGA), C++ (хост), Python (аналитика)

## 5. Функциональные возможности
1. Управление сканированием 4K CMOS-линейки
2. Покадровая обработка изображений на FPGA
3. Обнаружение аномалий методом PCA
4. Классификация дефектов (царапины, включения, неоднородности)
5. Построение карты дефектов по поверхности пластины
6. Отчёт в формате SECS/GEM для MES

## 6. Условия использования
Программное обеспечение разработано в рамках НИОКТР, финансируемого грантом
Фонда содействия инновациям (ФСИ «Старт-Пром-1», очередь 4).

## 7. Интеллектуальная собственность
Права на ПО принадлежат исполнителю НИОКТР. Патентование РИД финансируется
из собственных средств заявителя и не включено в бюджет гранта.

## 8. Аннотация
ОптикоЗор-Inspect — программное обеспечение, обеспечивающее высокоскоростной контроль поверхности полупроводниковых пластин: обнаружение, классификация и картирование дефектов.
Версия 1.0 является первой публичной версией, прошедшей стендовые испытания.
