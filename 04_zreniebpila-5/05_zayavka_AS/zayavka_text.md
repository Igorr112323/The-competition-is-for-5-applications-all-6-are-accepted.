## 2. ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ

| Параметр | Значение |
|----------|---------|
| Камера | Stereo OV9282 (global shutter, 1280×800, 60 fps) |
| Разрешение глубины | 640×400 @30 fps (stereo matching) |
| FoV | 80°×60° (каждый глаз) |
| Baseline | 60 мм |
| Обработка | Jetson Nano (472 GFLOPS, CUDA) |
| Алгоритм | YOLOv5-nano + optical flow + stereo matching |
| Детекция объектов | ≥100 м (БПЛА/вертолёт), ≥50 м (человек) |
| Скорость обработки | 30 fps |
| Масса модуля | ≤0.25 кг |
| Питание | 5V/3A от бортовой сети БПЛА |

---

## 3. НАУЧНАЯ НОВИЗНА

1. **Стереозрительный модуль с глубинным восприятием для БПЛА (stereo matching @30 fps)**
2. **Алгоритм обнаружения и классификации движущихся объектов (YOLOv5-nano + optical flow)**
3. **Адаптивная стабилизация изображения: компенсация вибрации БПЛА через IMU**
4. **Автономная обработка на Jetson Nano → не требуется наземная станция**
