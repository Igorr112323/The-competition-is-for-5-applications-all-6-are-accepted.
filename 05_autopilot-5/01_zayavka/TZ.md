# ТЕХНИЧЕСКОЕ ЗАДАНИЕ

## Проект: АвтоПилот-5
## Лот: 5.6 — Бортовое ПО автопилота
## Научный руководитель: Класнер Г.Г., к.т.н.

---

## 1. Наименование и краткая характеристика
АвтоПилот-5 — бортовое программное обеспечение автопилота с интеграцией SLAM + A* + DWA + PID для сельскохозяйственных роботов.

## 2. Научно-технический задел и новизна
Проект базируется на многолетнем заделе научного руководителя в области беспилотных систем и автоматизации АПК, подтверждённом патентами RU 2856133 C2, RU 2850431 C1, RU 2799531 C1 и публикациями 2020–2025, включая прототип «Умная ферма».

**Мост:** Аппаратная платформа беспилотных систем, защищённая патентами RU 2856133 C2, RU 2850431 C1, RU 2799531 C1, впервые дополняется собственным бортовым программным стеком (SLAM + A* + DWA + PID). **Научная новизна** — в комплексировании разнородных навигационных данных (LiDAR + IMU + одометрия) в едином бортовом pipeline. **Техническая новизна** — в бортовом ПО, работающем на серийных вычислителях (Raspberry Pi 4) без GPU при частоте ≥30 Гц.

**Риски переноса:** Минимальный. Аппаратная платформа proven (6 патентов). Проект — естественное развитие: hardware → software. Единственный риск — ограничения вычислительной мощности Raspberry Pi 4. Снимается оптимизацией алгоритмов (фиксированная точка, предвычисленные таблицы) и использованием SLAM-библиотеки с низким потреблением памяти.

## 3. Цель и задачи
**Цель:** создание экспериментального образца бортового ПО автопилота.

**Задачи:**
1. Проектирование архитектуры бортового pipeline
2. Разработка SLAM, A*, DWA, PID модулей
3. Лабораторные испытания на стенде
4. Полевые испытания на роботе
5. Подготовка документации и заявки на РИД

## 4. Требования к изделию
- Точность навигации ≤ 0.3 м
- Частота pipeline ≥ 30 Гц
- Автономность ≥ 3.6 ч
- CAN bus 500 кбит/с для актуаторов
