# ЗАЯВКА НА ПОЛУЧЕНИЕ ГРАНТА

## 1. Наименование проекта
**АвтоПилот-5**

## 2. Научный руководитель
**<ФИО>**, к.т.н., доцент, Класнер Г.Г.

## 3. Научный задел
Профессор Класнер Г.Г. имеет **6 патентов** на беспилотные системы (RU 2856133, 2850431, 2799531 и др.) и публикацию прототипа «Умная ферма» с экономическим обоснованием. Патенты закрывают **аппаратную часть беспилотника**: конструкцию, силовую установку, системы наведения.

## 4. Мост: задел → новая область
Существующие патенты (RU 2856133, 2850431, 2799531) закрывают **аппаратную часть** беспилотника. Новый проект — это **программная часть** (бортовое ПО, алгоритмы управления). Это **естественное развитие**: proven аппаратная платформа получает программный стек автономной навигации. Новизна: интеграция SLAM + A* + DWA + PID в единый бортовой pipeline для сельскохозяйственных роботов. Защищаемый результат: программный модуль бортового ПО автопилота.

## 5. Цель проекта
Создание бортового программного обеспечения автопилота для сельскохозяйственных роботов с полным стеком автономной навигации.

## 6. Техническое решение
- SLAM (LiDAR + IMU): drift 142-452 см/10 мин, карта 100×100 ячеек
- A* path planning: 10000 узлов, эвклидова метрика
- DWA local planner: горизонт 2 с, скорость до 3 м/с
- PID control: Kp=2.0, Kd=0.5, ограничение угла ±30°
- CAN bus 500 кбит/с для связи с актуаторами
- Pipeline 35 Гц на Raspberry Pi 4 (27.5 Вт)
