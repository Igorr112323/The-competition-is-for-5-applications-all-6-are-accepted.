## 1. АННОТАЦИЯ

Проект «АвтоПилот-5» — бортовое программное обеспечение автопилота для беспилотных самоходных платформ. Научная новизна — из 24 (6 на беспилотные системы) патентов Класнер и публикаций.

---

## 2. ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ

| Параметр | Значение |
|----------|---------|
| Платформа | STM32H743 + Jetson Nano |
| Навигация | SLAM (LiDAR + визуальная одометрия + IMU + одометрия) |
| Планирование | A* + DWA (Dynamic Window Approach) |
| Избегание препятствий | LiDAR 360° + УЗ×6, динамическое |
| Управление движением | PID-регулятор, CAN-интерфейс |
| Точность позиционирования | ±5 см (в помещении) |
| Рабочая скорость | 0.1-1.0 м/с |
| Протоколы | MAVLink, ROS2, CAN |
| Лицензия | Apache 2.0 (открытый код) |
| Стоимость ПО | Бесплатно (open source) + коммерческая поддержка |

---

## 3. НАУЧНАЯ НОВИЗНА

1. **Адаптивный SLAM для закрытых помещений (низкая освещённость, пыль, движущиеся препятствия)**
2. **Интеграция с CAN-шиной → управление любыми мобильными платформами (БПЛА, БПК, роботы)**
3. **ROS2-совместимость → модульная архитектура, plug-and-play**
4. **Русскоязычная документация и техническая поддержка**
