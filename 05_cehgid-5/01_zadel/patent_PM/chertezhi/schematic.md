# Электрическая схема ЦехГид-5

## Компоненты

| Обозначение | Тип / Модель | Назначение |
|---|---|---|
| SBC | Raspberry Pi 4B | Основной компьютер |
| IMU | BNO055 | 9-осевой инерциальный модуль |
| Лидар | RPLIDAR A3 | 360°, 16 м, 15 Гц |
| SHT45 | Sensirion | T/RH датчик |
| SGP41 | Sensirion | VOC датчик |
| SCD41 | Sensirion | CO₂ датчик |
| TSL2591 | Adafruit | Освещённость |
| LoRa | SX1276 | 868 МГц модуль |
| Драйвер моторов | L298N | H-мост ×2 |
| Моторы | JGB37-520 ×4 | DC 12В с энкодерами |
| Питание | LiFePO₄ 12V 6Ah | Аккумулятор |
| BMS | 12V LiFePO₄ BMS | Защита батареи |

## Соединения

| От | Куда | Интерфейс |
|---|---|---|
| Лидар | SBC | USB |
| IMU | SBC | I2C |
| SHT45 | SBC | I2C |
| SGP41 | SBC | I2C |
| SCD41 | SBC | I2C |
| TSL2591 | SBC | I2C |
| LoRa | SBC | SPI |
| Драйвер моторов | SBC | GPIO PWM |
| Моторы | Драйвер моторов | DC |
| Питание | BMS | 12V |
| BMS | SBC | 5V USB |
| BMS | Драйвер моторов | 12V |

*Текстовое описание электрической схемы. Графическая схема выполнена в формате DXF.*
