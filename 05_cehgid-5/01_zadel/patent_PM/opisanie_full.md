# Описание изобретения к заявке на патент Российской Федерации (полезная модель)

## Название

Навигационная система автономного мобильного робота для мониторинга параметров микроклимата в птицеводческих цехах

## Область техники

Изобретение относится к области «Точное животноводство» и может быть использовано для slam + многосенсорный мониторинг.

## Уровень техники

При напольном содержании птицы параметры микроклимата (T, RH, NH₃, CO₂, освещённость) существенно различаются по площади цеха (100×18 м). Стационарные датчики устанавливаются точечно (3–5 шт. на цех) и не отражают пространственное распределение. Ручное перемещение оператора с портативными приборами занимает 2–3 часа и стрессирует птицу.

### Аналоги (прототипы)

Стационарные системы мониторизма (Fancom, Big Dutchman) — фиксированные точки измерения. Роботизированные решения (Tibot, Hetitec) — узкая задача (разрыхление подстилки), не проводят мониторинг параметров воздуха. Системы на базе лидара для навигации (SLAM) применяются в складах и логистике, но не адаптированы для условий птицеводческих цехов (подстилка, помёт, высокая влажность, птица).

## Сущность изобретения

Автономный мобильный робот, содержащий: (а) шасси с клиренсом 150 мм и колёсами ∅200 мм с рисунком протектора для подстилки; (б) лидар RPLIDAR A3 (360°, 16 м, 15 Гц) для SLAM-навигации по алгоритму Cartographer; (в) блок сенсоров: SHT45 (T, RH), SGP41 (VOC), SCD41 (CO₂), TSL2591 (освещённость); (г) компьютер Raspberry Pi 4B + IMX BNO055; (д) модуль LoRa SX1276 для передачи данных на базовую станцию; (е) автономное питание 12 В LiFePO₄ ≥6 часов.

## Технический результат

Пространственное разрешение измерений ≤2 м (вместо 3–5 точек на весь цех); время полного обхода цеха 100×18 м ≤45 мин; снижение стресса птицы за счёт низкого уровня шума (≤55 дБ) и скорости перемещения ≤0.3 м/с; автоматическое построение карт распределения параметров.

## Краткое описание чертежей

Фиг. 1 — функциональная схема устройства.
Фиг. 2 — блок-схема алгоритма работы.
Фиг. 3 — внешний вид корпуса.

## Формула изобретения

**1. Навигационная система автономного мобильного робота для мониторинга параметров микроклимата в птицеводческих цехах**, содержащая шасси, лидарный модуль, блок сенсоров, вычислительный модуль и модуль связи, отличающаяся тем, что лидарный модуль выполнен на базе RPLIDAR A3 с обзором 360° и дальностью 16 м, блок сенсоров содержит датчики температуры и влажности SHT45, летучих органических соединений SGP41, углекислого газа SCD41 и освещённости TSL2591, вычислительный модуль выполняет SLAM-навигацию по алгоритму Google Cartographer, модуль связи выполнен на базе LoRa SX1276 с дальностью передачи до 5 км, при этом шасси имеет клиренс не менее 150 мм и колёса диаметром 200 мм с рисунком протектора для перемещения по подстилке, а скорость перемещения ограничена значением не более 0.3 м/с для снижения стресса птицы.

**2.** Способ эксплуатации системы по п. 1, включающий: инициализацию модулей;
проверку калибровки; проведение измерений; передачу данных; формирование отчёта.

**3.** Комплекс, включающий систему по п. 1 и серверное приложение для сбора,
хранения и визуализации данных мониторинга.
