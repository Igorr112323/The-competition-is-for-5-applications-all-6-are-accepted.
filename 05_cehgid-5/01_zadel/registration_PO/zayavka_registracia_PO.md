# Заявка на государственную регистрацию программы для ЭВМ

## 1. Наименование ПО
ЦехГид-Navigate версия 1.0

## 2. Назначение
SLAM-навигация автономного робота в птицеводческом цехе, сбор и визуализация данных микроклимата

## 3. Платформа
Raspberry Pi 4B / ROS2 Humble

## 4. Язык(и) программирования
Python, C++

## 5. Функциональные возможности
1. SLAM-картографирование по данным RPLIDAR A3 (алгоритм Cartographer)
2. Автономная навигация по маршрутному графу
3. Сбор данных от сенсоров: SHT45, SGP41, SCD41, TSL2591
4. Передача данных через LoRa SX1276
5. Построение тепловых карт распределения параметров
6. Генерация отчётов (PDF/CSV)

## 6. Условия использования
Программное обеспечение разработано в рамках НИОКТР, финансируемого грантом
Фонда содействия инновациям (ФСИ «Старт-Пром-1», очередь 4).

## 7. Интеллектуальная собственность
Права на ПО принадлежат исполнителю НИОКТР. Патентование РИД финансируется
из собственных средств заявителя и не включено в бюджет гранта.

## 8. Аннотация
ЦехГид-Navigate — программное обеспечение, обеспечивающее slam-навигация автономного робота в птицеводческом цехе, сбор и визуализация данных микроклимата.
Версия 1.0 является первой публичной версией, прошедшей стендовые испытания.
