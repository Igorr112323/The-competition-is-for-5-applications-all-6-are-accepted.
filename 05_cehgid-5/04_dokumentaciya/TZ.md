**Проект:** «ЦехГид-5»
**Полное наименование:** Создание навигационной системы автономного мобильного робота для пространственного мониторинга параметров микроклимата в птицеводческих цехах с напольным содержанием птицы

**Исполнитель:** ООО «Расчётная оценка проекта»

## 1. Наименование и область применения

Создание навигационной системы автономного мобильного робота для пространственного мониторинга параметров микроклимата в птицеводческих цехах с напольным содержанием птицы.

Применение: Робототехника / Точное животноводство / IoT.

## 2. Цель работы

Автономный робот с SLAM-навигацией (RPLIDAR A3, Cartographer), мультисенсорным блоком (T, RH, VOC, CO₂, освещённость), LoRa-передачей и временем обхода ≤45 мин.

## 3. Проблема

В птицеводческих цехах (100×18 м) параметры микроклимата неравномерны. Стационарные датчики (3–5 точек на цех) не отражают распределение. Ручной обход занимает 2–3 часа и стрессирует птицу.

## 4. Задачи

1. Проектирование шасси (клиренс 150 мм, колёса ∅200 мм, протектор для подстилки)
2. Интеграция RPLIDAR A3 + SLAM Cartographer на Raspberry Pi 4B
3. Блок сенсоров: SHT45, SGP41, SCD41, TSL2591
4. Модуль связи LoRa SX1276 (868 МГц, до 5 км)
5. Алгоритм маршрутного планирования (обход по сетке 2×2 м)
6. Визуализация: тепловые карты распределения параметров
7. Испытания в реальном цеху (100×18 м, напольное содержание)
