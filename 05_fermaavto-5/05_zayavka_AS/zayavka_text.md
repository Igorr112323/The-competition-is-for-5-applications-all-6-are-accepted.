## 1. АННОТАЦИЯ

Проект «ФермаАвто-5» создаёт модуль автономной навигации для беспилотных самоходных систем управления фермой. Модуль объединяет стереокамеру (CV), ультразвуковые дальномеры (6 шт.), одометрию и ИНС (IMU) для навигации в закрытом помещении птичника/коровника. Алгоритм: адаптивный SLAM (одновременная локализация и картирование) + CV для распознавания состояния сельскохозяйственных животных. Научная новизна — из 6 патентов Класнера на беспилотные самоходные системы (RU 2856133, 2850431, 2799531, 2787028, 2780844, 2768843) и 16 публикаций (14 РИНЦ/ВАК + 2 Scopus). Демонстрация — прототип навигационного модуля на макете птичника.

## 2. ПРОБЛЕМА И РЫНОК

**Проблема:** Российские птицефабрики и фермы КРС критически зависят от ручного труда: кормление, поение, сбор яиц, обработка подстилки, мониторинг здоровья животных. Импортные системы автономного управления (Big Dutchman, Lely, GEA) стоят 5–20 млн ₽ и находятся под санкциями. Отечественные аналоги отсутствуют. Ручной труд — 60–70% эксплуатационных расходов фермы.

**Решение:** навигационный модуль за 2 000 000 ₽, интегрируемый в существующие и новые беспилотные самоходные платформы. SLAM для навигации в помещении (GPS не работает), CV для мониторинга животных. Модульная архитектура — подключение к любой мобильной платформе через стандартный интерфейс (CAN / UART / Ethernet).

**Рыночный потенциал (расчётная оценка проекта):**
- Птицефабрики РФ: 3 000 × 3 000 000 ₽ = **9 млрд ₽**
- Фермы КРС: 100 000 × 2 000 000 ₽ = **200 млрд ₽**
- Свиноводческие комплексы: 5 000 × 3 000 000 ₽ = **15 млрд ₽**
- Экспорт (СНГ, Ближний Восток, Африка): потенциально **50+ млрд ₽**

## 3. НАУЧНАЯ НОВИЗНА

1. **Адаптивный SLAM для сельскохозяйственных помещений** — алгоритм одновременной локализации и картирования, адаптированный к условиям птичника/коровника: низкая освещённость, высокая запылённость, аммиачная агрессия, подвижные препятствия (животные). Используется гибридная карта: 2D LiDAR-карта (ультразвуковые дальномеры) + визуальные ключевые точки (стереокамера). Точность позиционирования: ±5 см при скорости 0.1–0.5 м/с.

2. **CV-модуль распознавания состояния животных** — алгоритм компьютерного зрения для оценки уровня активности, поведения при кормлении, обнаружения аномалий позы (хромота, апатия, агрессия). Классификатор: HOG + SVM (без глубокого обучения, прозрачно). Точность классификации: ≥85% на контрольной выборке.

3. **Мультисенсорное слияние** — камера + УЗ-дальномеры + одометрия + IMU. Алгоритм фильтра Калмана для слияния данных датчиков с разной частотой дискретизации (камера 30 Гц, УЗ 10 Гц, IMU 100 Гц, одометрия 50 Гц).

4. **Двойное применение** — гражданское (фермы) + военное (автономные транспортные средства в закрытых помещениях, склады, логистика).

## 4. СПОСОБЫ И МЕТОДЫ

### 4.1. Аппаратная часть

| Модуль | Компоненты | Параметры |
|--------|-----------|-----------|
| Стереокамера | OV9282 (global shutter, 1280×800, 60 fps) | Визуальная одометрия + CV |
| УЗ-дальномеры | HC-SR04 × 6 (30–400 см) | 360° покрытие |
| IMU | MPU6050 (акселерометр + гироскоп, 6 осей) | 100 Гц |
| Одометрия | Энкодеры на колёсах (400 имп/об) | Точность ±1 см/м |
| Контроллер | Jetson Nano (CUDA, 472 GFLOPS) | SLAM + CV |
| Связь | WiFi 5 ГГц + LoRa 868 МГц | Удалённый мониторинг |
| Аккумулятор | LiFePO4 12 В, 20 А·ч | 8 ч работы |
| Корпус | Алюминий + PLA (3D-печать) | 120×80×40 мм, ≤0.5 кг |

### 4.2. Программная часть

1. Визуальная одометрия (Visual Odometry): отслеживание ключевых точек между кадрами
2. УЗ-сканирование: построение 2D карты препятствий (360°, 10 Гц)
3. IMU + одометрия: инерциальная навигация между обновлениями визуальной одометрии
4. SLAM: гибридная карта (2D occupancy grid + visual landmarks)
5. Фильтр Калмана: слияние данных 4 датчиков
6. CV: HOG + SVM классификатор состояния животных
7. Планирование пути: A* на occupancy grid + динамическое избегание препятствий
8. BLE/WiFi: передача данных на центральный сервер

### 4.3. Технические характеристики
