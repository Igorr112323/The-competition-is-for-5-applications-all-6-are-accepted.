# ТЕХНИЧЕСКОЕ ЗАДАНИЕ — ИнспекторФерма-5
## ТЗ на НИОКТР: Автономный робот-инспектор для птицеводческих ферм

**Шифр:** ИнспекторФерма-5
**Научный руководитель:** Класнер Г.Г. — д.т.н.
**Срок:** 12 месяцев | **Бюджет:** 5 000 000 ₽

---

## 1. НАЗНАЧЕНИЕ
Автономный робот-инспектор для мониторинга птицеводческих ферм: ИК-термография, газоанализ, влажность, освещённость.

## 2. ТРЕБОВАНИЯ К СОСТАВУ
- Мобильная платформа: 4 мотор-колеса, рама 600×400×300 мм, IP54
- ИК-камера: FLIR Lepton 3.5 (160×120 px)
- Газоанализатор: NH₃ (MQ-137), CO₂ (SCD30), H₂S (MQ-136)
- Навигация: LiDAR (RPLIDAR A1) + одометрия
- Контроллер: Raspberry Pi 4 + STM32
- Связь: Wi-Fi → MQTT → Grafana

## 3. ТРЕБОВАНИЯ К ХАРАКТЕРИСТИКАМ
| Параметр | Значение |
|----------|---------|
| Скорость патрулирования | 0.2–0.5 м/с |
| Площадь птичника | до 5 000 м² |
| Цикл патрулирования | 30–60 мин |
| Время работы | 6–8 ч |
| Точность ИК | ±2°C |
| Порог NH₃ | 25 ppm |
| Стоимость | ≤500 000 ₽ |

## 4. МЕТОДЫ ПРОВЕРКИ
- Испытания навигации: птичник 500 м², замер точности позиционирования
- Испытания ИК: макеты птиц с нагревателями (40–44°C), замер точности
- Испытания газоанализа: эталонные газы (NH₃ 10–50 ppm), замер погрешности
