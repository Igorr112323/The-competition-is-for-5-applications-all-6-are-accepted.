# ФОРМУЛА ПОЛЕЗНОЙ МОДЕЛИ
## «Автономный мобильный робот мониторинга микроклимата замкнутых пространств»

---

1. Автономный мобильный робот, содержащий лидар RPLIDAR A3 для SLAM-навигации, мультисенсорный блок (SHT45, SGP41, SCD41, TSL2591, NTC), Raspberry Pi 4B, LoRa SX1276 (868 МГц), шасси с клиренсом 150 мм и колёсами ∅200 мм, LiFePO₄-батарею с BMS, отличающийся тем, что содержит маршрутный граф (сетка 2×2 м) для автономного обхода помещения и сбора данных каждые 2 м с построением тепловых карт распределения параметров микроклимата.

2. Автономный мобильный робот по п. 1, отличающийся тем, что SLAM-навигация выполнена на базе алгоритма Google Cartographer с точностью позиционирования ±5 см.

3. Автономный мобильный робот по п. 1, отличающийся тем, что данные передаются по LoRa (868 МГц) на базовую станцию с дашбордом визуализации тепловых карт.
