# ТЕХНИЧЕСКОЕ ЗАДАНИЕ
## на выполнение НИОКТР

**Проект:** «КлиматРобот-5»
**Полное наименование:** Разработка автономного мобильного робота мониторинга микроклимата замкнутых пространств с SLAM-навигацией и мультисенсорным блоком
**Область:** Робототехника / SLAM / IoT / Точное животноводство
**Руководитель:** Класнер Г.Г.
**Исполнитель:** ООО «Расчётная оценка проекта»

---

## 1. Наименование и область применения

Разработка автономного мобильного робота (≤15 кг, 400×300×250 мм) для пространственного мониторинга параметров микроклимата в замкнутых помещениях с SLAM-навигацией по лидарным данным.

## 2. Цель работы

Создание автономного мобильного робота мониторинга микроклимата (TRL ≥ 5) с SLAM-навигацией (RPLIDAR A3, ±5 см), 5 датчиками (T, RH, VOC, CO₂, освещённость), LoRa-передачей, автономностью ≥6 ч.

## 3. Проблема

Мониторинг микроклимата в фермах, складах, теплицах требует ручного обхода (4 часа, 500 ₽/час) или установки дорогостоящей стационарной сети датчиков. Существующие роботы-мониторы не адаптированы к сельскохозяйственным помещениям (высокая влажность, пыль, неровный пол).

## 4. Задачи

1. Разработка SLAM-алгоритма на базе RPLIDAR A3 и Google Cartographer
2. Интеграция 5 датчиков (SHT45, SGP41, SCD41, TSL2591, NTC)
3. Разработка маршрутного графа (сетка 2×2 м) для обхода помещения
4. LoRa-передача данных (868 МГц) на базовую станцию
5. Корпус из PLA (3D-печать) + шасси с клиренсом 150 мм
6. Испытания в помещении 500 м²
7. Подача заявки на ПМ и регистрацию ПО
