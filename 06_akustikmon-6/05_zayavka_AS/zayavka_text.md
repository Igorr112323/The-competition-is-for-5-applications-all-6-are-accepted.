## 2. ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ

| Параметр | Значение |
|----------|---------|
| Микрофон | MEMS, 20-20 000 Гц, SNR 65 дБ |
| АЦП | 24 бит, 48 кГц |
| FFT | 4096 точек, разрешение 11.7 Гц |
| Анализ голоса | Частота основного тона (F0), форманты, jitter, shimmer |
| Анализ дыхания | Частота, глубина, регулярность (ЧДД) |
| Анализ кашля | Детекция, классификация (сухой/влажный), частота |
| Масса | ≤30 г (носимый модуль) |
| Связь | BLE 5.0 → смартфон |
| Питание | CR2450×2, 100 ч |
| Стоимость | ≤50 000 ₽ |

---

## 3. НАУЧНАЯ НОВИЗНА

1. **Три канала акустического анализа: голос + дыхание + кашель в одном устройстве**
2. **FFT-анализ (4096 точек) + MFCC-признаки + ML-классификация**
3. **Детекция и классификация кашля: сухой/влажный, частота, тяжесть**
4. **Носимый форм-фактор (30 г) с BLE → непрерывный мониторинг 100 ч**
