# Электрическая схема Смена-Прогноз-40

## Компоненты

| Обозначение | Тип / Модель | Назначение |
|---|---|---|
| MCU | nRF52832 | BLE 5.0 микроконтроллер |
| PPG | AFE4404 | Аналоговый фронтенд пульсометра |
| Светодиоды PPG | Зелёный + ИК | 525 нм + 940 нм |
| Термометр | MLX90614 | ИК-термометр кожи ±0.2°C |
| КГР | AD5940 | Биоимпеданс EDA |
| Акселерометр | LIS2DH12 | 3-осевой ±16g |
| Вибромотор | ERM 10×3мм | Тактильная обратная связь |
| Питание | LiPo 3.7V 250мАч | Миниатюрный аккумулятор |
| Стабилизатор | TPS62740 | DC-DC 1.8В ультрамалый IQ |

## Соединения

| От | Куда | Интерфейс |
|---|---|---|
| PPG | MCU | SPI |
| Светодиоды PPG | PPG | LED驱动 |
| Термометр | MCU | I2C |
| КГР | MCU | SPI |
| Акселерометр | MCU | I2C |
| Вибромотор | MCU | GPIO + MOSFET |
| Питание | Стабилизатор | 3.7В |
| Стабилизатор | MCU | 1.8В / 3.3В |

---
*Текстовое описание электрической схемы. Графическая схема выполнена в формате DXF.*
