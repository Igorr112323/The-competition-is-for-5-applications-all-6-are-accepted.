# Заявка на государственную регистрацию программы для ЭВМ

## 1. Наименование ПО
Смена-Прогноз версия 1.0

## 2. Назначение
Мониторинг физиологических параметров работников и прогноз теплового стресса с горизонтом 40 минут

## 3. Платформа
nRF52832 / Android / Cloud

## 4. Язык(и) программирования
C (прошивка), Python (ML), Kotlin (приложение)

## 5. Функциональные возможности
1. Сбор данных: PPG (ЧСС), MLX90614 (T кожи), КГР (EDA), акселерометр
2. BLE-передача на мобильное приложение / LoRa-шлюз
3. Инференс модели CatBoost (прогноз теплового стресса)
4. Генерация предупреждений (вибрация, push-уведомление)
5. Дашборд для диспетчера (WebSocket)
6. История смен и аналитика рисков

## 6. Условия использования
Программное обеспечение разработано в рамках НИОКТР, финансируемого грантом
Фонда содействия инновациям (ФСИ «Старт-Пром-1», очередь 4).

## 7. Интеллектуальная собственность
Права на ПО принадлежат исполнителю НИОКТР. Патентование РИД финансируется
из собственных средств заявителя и не включено в бюджет гранта.

## 8. Аннотация
Смена-Прогноз — программное обеспечение, обеспечивающее мониторинг физиологических параметров работников и прогноз теплового стресса с горизонтом 40 минут.
Версия 1.0 является первой публичной версией, прошедшей стендовые испытания.
