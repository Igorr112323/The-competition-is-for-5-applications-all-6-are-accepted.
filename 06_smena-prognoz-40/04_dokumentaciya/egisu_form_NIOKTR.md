# ЧЕРНОВИК ФОРМЫ ЕГИСУ НИОКТР

## Наименование НИОКР

Носимая мультисенсорная платформа прогноза состояния работника с ансамблевым алгоритмом и динамической индивидуальной нормой

## Аннотация (реферат)

Разработка пак (браслет + lora-шлюз, партия 20 шт.) + по прогноза состояния для решения задач дистанционный мониторинг состояния в рамках конкурса ФСИ «Старт-Пром-1», очередь 4.

## Область применения

Дистанционный мониторинг состояния

## Ожидаемые результаты
