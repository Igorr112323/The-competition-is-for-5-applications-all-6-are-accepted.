## НОВЫЕ ТЕМЫ

### Т01 — ПАПУША С.К. → «ОпрыскАдапт-6»

**Лот:** 6.8 «Платформы для обработки данных с нескольких датчиков и прогнозирования состояния»

**Концепция:** Система адаптивного дозирования для садовых УМО-опрыскивателей с LiDAR-сенсором плотности кроны и аэродинамической моделью дрейфа капель.

**Суть:** Опрыскиватель получает данные с LiDAR (плотность кроны), анемометра (ветер), расходомера (давление/расход). Алгоритм на основе аэродинамической модели (из патентов Папуши) вычисляет оптимальную норму расхода и размер капли. Дозирование — через PWM-насос и переменные форсунки.

**Демонстрация:** Стенд на столе: PWM-насос + 4 форсунки + LiDAR-сенсор + анемометр + контроллер. Макет «дерева» из пенопласта. Визуально: расход меняется в зависимости от «плотности кроны».

**Патенты в ядре:**
- RU 2768841 C1 — УМО-опрыскиватель садовый
- RU 2710722 C1 — УМО-опрыскиватель камерный
- RU 2707628 C1 — УМО-опрыскиватель
- RU 2693258 C1 — обработка клубней
- RU 2683510 C1 — внесение жидкостей

**Публикации:** Учебное пособие «Точное земледелие». 39 публикаций по аэродинамике распыления.

**Проверка «убери задел»:** ДА. Без патентов на УМО нет конструкции опрыскивателя. Без аэродинамики распыления нет модели дрейфа. Без учебного пособия нет методологии точного земледелия.

### Т04 — БОГУС А.Э. → «СеятельАвтоном-5»

**Лот:** 5.5 «Модули для сельскохозяйственных робототехнических платформ (управление навесным оборудованием, точный высев)»

**Концепция:** Автономный мобильный робот с пневматическим высевающим аппаратом и навигацией на основе иерархического ансамблевого алгоритма прогнозирования траектории.

**Суть:** Малогабаритный робот (600×400×300 мм, ≤25 кг) для точного высева на малых участках, в теплицах, на неровном рельефе. Пневматический высевающий аппарат (из патентов Богуса) обеспечивает точное дозирование семян. Навигация — SLAM (LiDAR) + ансамблевый прогноз (ARIMA + RF + GBM + мета-модель, публикация 2026). Робот адаптирует скорость и норму высева в зависимости от рельефа и плотности почвы.

**Демонстрация:** Стенд на столе: макет робота (колёса + пневматический аппарат) + LiDAR + контроллер. Визуально: робот перемещается по «полю» (лист фанеры с маркерами), высевает «семена» (пшено) с переменной плотностью.

**Патенты в ядре:**
- RU 2797425 C1 — пневматический высевающий аппарат
- RU 2448444 C1 — пневматическая сеялка с ЦДС
- RU 2448445 C1 — пневматическая сеялка
- RU 230461 U1 — посевная секция
- RU 131936 U1 — распределитель семян

**Публикации:** 2026 — ансамблевый прогноз (ej.kubagro id=9685). 2020–2021 — движение семян в воздушном потоке.

**Проверка «убери задел»:** ДА. Без патентов на пневматику нет высевающего аппарата. Без публикации 2026 нет алгоритма навигации.

### Т05 — КЛАСНЕР Г.Г. → «ИнспекторФерма-5»

**Лот:** 5.5 «Модули для сельскохозяйственных робототехнических платформ»

**Концепция:** Автономный мобильный робот-инспектор для птицефабрик с ИК-термографией и газоанализатором (NH₃, CO₂) для раннего выявления больных птиц и зон дискомфорта.

**Суть:** Робот на базе шасси из патентов Класнера (RU 2856133, RU 2850431) перемещается по птичнику по маршрутному графу (SLAM, RPLIDAR A3). ИК-камера (MLX9064A) сканирует температуру тела птиц — больные птицы имеют повышенную температуру. Газоанализатор (SGP41 + SCD41) контролирует NH₃ и CO₂ — зоны с плохой вентиляцией. Данные передаются по LoRa на базовую станцию. Алгоритм прогнозирования (ансамблевый метод Богуса) предсказывает вспышки заболеваний за 24–48 часов.

**Конкурент:** SimpliFly (дрон-инспектор, ~300 000 ₽, не работает в помещениях). Наш робот: 150 000 ₽, работает в помещении 24/7.

**Демонстрация:** Макет птичника (коробка 1×0.5 м) + робот (модифицированный «Умная ферма») + ИК-сенсор + газоанализатор. Робот обходит макет, находит «горячую точку» (лампа накаливания), передаёт данные.

**Патенты в ядре:**
- RU 2856133 C2 — беспилотное устройство поения птицы
- RU 2850431 C1 — беспилотная система содержания птицы
- RU 2799531 C1 — беспилотная система кормления
- RU 2780844 C1 — беспилотный сбор яиц
- RU 2768843 C1 — беспилотная система поения
- RU 2787028 C1 — обработка подстилки

**Прототип:** «Умная ферма» (2023) — 200+ часов на подстилке.

**Проверка «убери задел»:** ДА. Без патентов на самоходные устройства для птичников нет носителя. Без прототипа «Умная ферма» нет доказательства работы на подстилке. Без 24 патентов нет навигационного ядра.

### Т06 — САМУРГАНОВ Е.Е. → «ЗерноВибро-6»

**Лот:** 2.4 «Мобильные средства диагностики качества продовольствия»

**Концепция:** Портативный прибор для экспресс-оценки качества зерна методом вибрационного анализа на основе технологии виброожиженного слоя с энергосберегающим контуром.

**Суть:** Прибор (≤800 г) анализирует качество зерна по вибрационным характеристикам. Проба зерна (50–100 г) помещается в вибрационную камеру. Датчик ускорения (ADXL355) регистрирует спектр вибрации частиц. По характерным частотам определяется: влажность (±1%), засорённость (±2%), натура (±3%). Результат — за 30 секунд на OLED + в мобильном приложении (BLE). Встроенная библиотека эталонных спектров (пшеница, кукуруза, ячмень, рожь, овёс). Энергосберегающий контур (из публикации 2025) обеспечивает ≥8 часов автономной работы.

**Демонстрация:** Стенд: вибрационная камера + датчик ускорения + контроллер + OLED. Проба зерна в стаканчике → прибор вибрирует → анализ спектра → результат на экране.

**Патенты в ядре:**
- RU 2766207 C1 — установка для исследования смешивания кормов (измерительный контур)
- RU 207049 U1 — сенсорный узел
- RU 174662 U1 — сито (анализ частиц)
- RU 2764990 C1 — устройство для длинностебельных кормов

**Публикации:** 2025 — рекуперативный привод (энергоконтур). 2016 — виброожиженный слой зерна. 2021 — air-sieve grain-cleaning machines (обработка сигналов).

**Проверка «убери задел»:** ДА. Без патента на сито (RU 174662 U1) нет вибрационной камеры. Без публикации 2016 (виброожиженный слой) нет физической модели. Без публикации 2025 (энергоконтур) нет автономности.

### Т03 — КРЕМЯНСКИЙ В.Ф. → «КормТест-NIR v2»

**Лот:** 2.4 «Мобильные средства диагностики качества продовольствия»

**Концепция:** Портативный NIR-экспрессанализатор кормов со встроенной библиотекой эталонных спектров (без ИИ). Определяет вид корма по корреляции спектра с эталонами.

**Суть:** Прибор (≤500 г) содержит NIR-модуль (900–1700 нм), OLED-дисплей, BLE 5.0. В памяти — библиотека из 50–100 эталонных спектров кормов (пшеница, кукуруза, соя, шрот, гранулы, мука и т.д.). Проба освещается NIR → полученный спектр сравнивается с эталонами по методу корреляции (коэффициент Пирсона) → определяется вид корма и его характеристики (протеин, жир, влажность) из справочника. **Никакого ИИ** — простая корреляция. Образцы для библиотеки получены на экструдере и грануляторе Кремянского (RU 2734521, RU 2813529).

**Демонстрация:** Стенд: NIR-модуль + контроллер + OLED + 10 проб кормов в стаканчиках. Прибор определяет вид корма из 10 вариантов за 2–3 минуты.

**Патенты в ядре:**
- RU 2813529 C1 — питатель гранулятора (источник образцов)
- RU 2734521 C1 — экструдер (источник образцов)
- RU 2547921 C1 — почвообработка
- RU 2782425 C1 — перчатка пчеловода

**Публикации:** 2023/2025 — эффективность мази при ранах КРС. 2025 — High Protein Soy Feed.

**Проверка «убери задел»:** ЧАСТИЧНО. Патенты Кремянского — на экструзию, не на NIR. Но: библиотека эталонных спектров строится на образцах из экструдера/гранулятора Кремянского. Задел = «кормовой контур» + справочник. Для усиления: NIR-модуль — стандартный (Analog Devices ADPD188BI), не требует разработки.
