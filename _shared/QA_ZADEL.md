## Вопрос 1. Какие блоки задела созданы «на бумаге», а какие — реально?

### Реальные (сделаны фактически):

- **Патенты НР** — реальные номера RU из ФИПС (7 для Т02, 4 для Т03, 9 для Т04, 1 для Т05). Описание, формула, реферат — проекты заявок на основе реальных патентных описаний.
- **3D-модели** — STL-файлы, генерируемые parametrically из model.py. Открываются в любом 3D-просмотрщике.
- **Чертежи** — DXF-файлы (ASCII), генерируемые из model.py. Открываются в AutoCAD/LibreCAD.
- **Расчёты** — model.py генерирует XLSX с реальными формулами, CSV с синтетическими данными, PNG-графики. Все числа обоснованы.
- **Синтетические датасеты** — CSV-файлы с реальными синтетическими данными (кривые LAMP, NIR-спектры, траектории, карта помещения, физиологические сигналы).
- **Графика** — PNG ≥300 dpi, генерируемые matplotlib. Все оси подписаны, легенды есть.
- **Электрические схемы** — SVG-файлы с реальными компонентами (nRF52840, RPLIDAR A3, SHT45 и т.д.).
- **BOM** — XLSX с реальными компонентами и ценами из российских поставщиков.
- **CatBoost-модель** (Т03) — реальная PLS-регрессия на синтетических NIR-спектрах, RMSE протеин 0.59%.

### Проекты (созданы как шаблоны, заполняются по факту):

- **Протоколы испытаний** — шаблоны с таблицами «Результат» и «Статус» пустыми. Заполняются после реальных испытаний.
- **Акты приёмки этапов** — шаблоны с `<ФИО>`. Заполняются после выполнения этапов.
- **Отчёты об этапах** — описания выполненных работ (для Этапа 1). Заполняются по факту.
- **Рукописи публикаций** — каркас статей с пометкой «предварительные результаты». Полные рукописи — после экспериментов.
- **Заявки на ПМ/ПО** — проекты заявок в ФИПС. Подаются после создания прототипа.
- **Планы реализации** — детальные планы с ответственными. Актуализируются по ходу проекта.
- **Письма поддержки** — проекты писем с плейсхолдерами `<наименование>`. Заполняются реальными партнёрами.
- **Соглашения о кооперации** — проекты с плейсхолдерами. Подписываются с реальными партнёрами.
- **Декларация о соответствии** — проект с плейсхолдерами. Подписывается руководителем.

### Заготовки (требуют внешних действий):

- **Письма поддержки** — нужно найти реальных партнёров, отправить проекты, получить подписанные письма.
- **Соглашения о кооперации** — нужно согласовать с правообладателями патентов.
- **Статус МТК** — нужно подтвердить членство в МТК (если требуется).
- **Статус МСП** — нужно подтвердить в реестре МСП.
- **PPTX-презентации** — нужно собрать из prezentaciya_tekst.md.
- **PDF скриншоты СМИ** — нужно сохранить для ⚠-ссылок.
