## 3. Оформление осей и легенды

- Оси: подписаны на русском языке, единицы СИ в скобках.
  - Пример: «Температура (°C)», «Мощность (Вт)», «Время (мин)».
- Легенда: размещена внутри графика (верхний правый угол) или под графиком, если мешает данным.
- Сетка: тонкая (#E5E7EB), пунктир для вспомогательных линий.
- Нулевая линия: сплошная, толще сетки.

## 4. Экспорт и разрешение

| Формат | Разрешение    | Назначение                     |
|--------|---------------|--------------------------------|
| PNG    | ≥ 300 dpi     | Вставка в DOCX/PDF, печать     |
| SVG    | вектор        | Редактируемые схемы, веб       |
| XLSX   | —             | Расчёты (исходные данные)      |

- Формулы и оси в matplotlib/seaborn задавать через API, не вручную.
- При экспорте PNG: `dpi=300, bbox_inches='tight', facecolor='white'`.

## 5. Типовые шаблоны графиков

| Тип                      | Библиотека   | Примечание                              |
|--------------------------|-------------|-----------------------------------------|
| Линейный                 | matplotlib  | До 4 серий; точки маркерами ≥ 4 pt      |
| Столбчатый               | matplotlib  | Ширина столбцов 0.6–0.8; подписи знач. |
| Тепловая карта           | seaborn     | Цветовая шкала: основной → третичный    |
| Диаграмма рассеяния      | matplotlib  | Маркеры ≥ 6 pt; тренды — пунктир        |
| Временной ряд            | matplotlib  | Fill_between для зон допуска            |
| Блок-схема               | SVG (ручная)| Белый фон, рамки 2 px, основной цвет    |

## 6. Обязательные элементы каждого графика

1. **Заголовок** (русский, информативный).
2. **Подписи осей** (русский + единицы СИ).
3. **Легенда** (если > 1 серии).
4. **Источник** — под графиком курсивом 8 pt:
   - Пример: «Источник: расчёт проекта по данным [URL, дата проверки]».
   - Без источника — не выпускать.
5. **Масштаб и единицы** — проверены.

## 7. Антипаттерны (запрещено)

- Водяные знаки, стоковые изображения.
- Растровые подписи с разрешением < 300 dpi.
- 3D-графики без необходимости.
- Более 5 серий на одном графике (без панелей).
- Цвета вне палитры (кроме чёрного #000000 для тонких линий).
