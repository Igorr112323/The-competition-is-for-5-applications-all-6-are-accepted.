## Шаблоны документов

**Проект:** 6 заявок Старт-Пром-1, очередь 4.

### Содержимое

| Файл                    | Назначение                         |
|-------------------------|------------------------------------|
| `шаблон_ТЗ.md`          | Техническое задание (ТЗ)           |
| `шаблон_КП.md`          | Калькуляция/смета (КП)             |
| `шаблон_протокол.md`    | Протокол испытаний                 |
| `шаблон_акт.md`         | Акт приёмки                        |
| `шаблон_отчёт.md`       | Отчёт по этапу                     |
| `шаблон_письмо.md`      | Письмо поддержки / о намерениях    |
| `шаблон_соглашение.md`  | Соглашение о кооперации / лицензии |

### Правила

- Копировать шаблон в папку темы и дополнять конкретными данными.
- В шаблоне `[placeholder]` — заменить на реальные данные.
- ФИО — только в формах АС Фонд-М; в ТЗ, КП и презентациях — роли и квалификация.
