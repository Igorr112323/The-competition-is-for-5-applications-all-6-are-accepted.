# ПРАВИЛА РАБОТЫ С ИСТОЧНИКАМИ (СМИ, ссылки)

**Проект:** 6 заявок Старт-Пром-1, очередь 4.
**Версия:** v1 — 06.10.2026.

---

## 1. Общие принципы

1. **Не выдумывать** ни один факт, число, URL, DOI, название организации или цитату.
2. Всё, что не подтверждено источником или измерением, помечается:
   - **«расчётная оценка проекта»** — для числовых оценок.
   - **«не найдено»** — для фактов, которые не удалось подтвердить.
3. В таблицы попадают только ссылки со статусом **«200 ✓»**.
4. Статусы **«403/503 ⚠»** — помечаются как «проверить вручную».
5. Статусы **«404 ✗»** — **не используются и удаляются**.

## 2. Требования к источнику

| Критерий          | Требование                                            |
|--------------------|-------------------------------------------------------|
| Дата публикации    | 2022–2026 (актуальность)                              |
| Тип                | Новостное СМИ, отраслевой портал, гос. статистика, научная статья, прайс-лист, патентная база |
| Доступность        | URL открывается, контент читаемый                      |
| Проверяемость      | URL + дата проверки фиксируются                       |
| Язык               | Русский или английский                                |

## 3. Формат записи источника

```
[N] Название. Источник. URL: https://... Проверено: ДД.ММ.ГГГГ.
```

Пример:
```
[1] Обзор рынка спецодежды 2025. MegaResearch. URL: https://megaresearch.ru/... Проверено: 07.10.2026.
```

В таблицах СМИ:
```
| № | Название / Событие           | Источник         | Дата       | URL   | Статус   |
|---|-------------------------------|------------------|------------|-------|----------|
| 1 | Обзор рынка спецодежды        | MegaResearch     | 2025       | ...   | 200 ✓    |
```

## 4. Проверка ссылок (машинная)

- Инструмент: `curl -o /dev/null -s -w "%{http_code}" <URL>`
- Автоматическая проверка при каждом обновлении таблицы СМИ.
- Результат в столбец **Статус**.
- Лог проверки: `smi_check_log.csv` (дата, URL, код, ответ).
- Проверять не реже 1 раза в день до 11.10 включительно.

## 6. Антипаттерны (запрещено)

- Ссылки на заблокированные/платные ресурсы без альтернативы.
- Цитаты из СМИ без указания автора и даты.
- Прайсы без указания даты проверки.
- «По данным экспертов» без конкретного источника.
- Устаревшие источники (до 2022 г.) — только в историческом контексте, с обоснованием.

## 7. Резервные источники

Если основной источник «404 ✗»:
1. Искать архив (web.archive.org).
2. Искать альтернативный источник того же факта.
3. Если не найдено — пометить «не найдено» и исключить из таблицы.
